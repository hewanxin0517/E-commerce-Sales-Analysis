# E-commerce-Sales-Analysis
# 电商销售数据多维度交叉分析 (Superstore Dataset)

## 📌 1. 业务背景与假设
假设我们是一家电商公司的分析团队，目标是在不增加额外营销预算的前提下，寻找销售额贡献最大的核心阵地，并识别潜在的交叉销售机会。

## 🛠️ 2. 工具与数据源
* **数据源**：Kaggle 公开数据集 (Superstore Sales)，原始记录约 9,800 条。
* **处理工具**：DBeaver (SQL 数据提取与聚合) + Excel (数据可视化)。

## 🧹 3. 数据清洗与口径说明
* 在导入数据库过程中，剔除了含非法分隔符及关键字段缺失的异常“脏数据”。
* 最终分析基于 1,066,698.62 的有效销售样本展开（约占原始全量的 47%），能够反映结构性占比特征。
* 图表纵轴单位已统一转换为“万”。

## 💡 5. 业务洞察与下一步建议
* **客群与区域**：个人消费者（Consumer）贡献了最大销售份额；西部区域（West）是最大的销售阵地。
* **品类结构**：科技（Technology）略占优势，三大品类销售额分布相对均衡。
* **策略建议**：针对“西部区域 + 个人消费者”，建议推出“买科技产品搭配办公用品享折扣”的交叉销售（Cross-selling）套餐。

## ⚠️ 6. 项目局限性
本数据集缺乏成本、利润、获客渠道及退货率等财务运营字段。因此本次分析仅代表“销售规模”盘面，无法断言某客群“最赚钱”。若接入真实企业数仓，需 `JOIN` 财务表进行深度 ROI 评估。
